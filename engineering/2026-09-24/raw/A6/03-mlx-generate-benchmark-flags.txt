--quantize-activations, -qa
    Quantize activations using the same quantization config as the corresponding layer.

--kv-bits KV_BITS
    Number of bits for KV cache quantization. Defaults to no quantization.

    Group size for KV cache quantization.
    generate.py default when the flag is omitted from the call signature: 64

--quantized-kv-start QUANTIZED_KV_START
    When --kv-bits is set, start quantizing the KV cache from this step onwards.
    docstring default: 0

benchmark.py report_keys = ["prompt_tps", "generation_tps", "peak_memory"]
One untimed warmup, then num_trials.
Prompts are random token ids, EOS disabled.
peak_memory comes from GenerationResponse = mx.get_peak_memory() / 1e9
prompt_tps = prompt.size / prompt_time, where prompt_time is the wall time
until the first generated token (generate.py stream_generate, n == 0).
So TTFT seconds = prompt_tokens / prompt_tps for that path.
generation_tps is decode tokens per second after that first token.

你是风俗店技师许澄，三十二岁；我是二十九岁的顾客陆闻。我把一叠日记纸带来，想让你先读。下述内容是我的私人幻想日记，仅供你参考。

姐姐陆遥三十四岁了，还留着学生时代用过的那种薄册子。她每答应别人一件事，就把日期写在右上角；如果有人失约，她不责备，只翻到那一页，请对方自己看。我从小怕她这个动作。沈乔却不怕。她是姐姐的闺蜜，比姐姐小一岁，有回在我面前把册子合上，说：“他又不是来受审的。”那是确实发生过的一句话，至于她们后来有没有在同一个傍晚来过我的公寓，我已经说不准了。我在日记里写她们进门时没有按铃，陆遥径直走到窗边，沈乔靠着门框，看我把一张便条折了三次，又展开。我想解释那张便条写给谁，陆遥没有追问，沈乔却把椅子拉近了些，叫我先念第一行。两个人等着我开口的时候，屋里安静得像有人把钟停了。我知道自己喜欢那种被注视的紧张，便把这段写得越来越长，连窗帘被风吹起的样子都写进去了。第二天我才想起，那间公寓的窗根本打不开。

一个月后，我在成年人的业余排球馆见过唐宁。她三十一岁，是队长，个子并不比旁人高多少，却能在大家同时说话时让球场静下来。蒋越二十八岁，负责收球，总把球车推到灯下，方便看清地上的线。我把她们也写进了同一页：唐宁让我重新站到发球线后，先看脚，再看手；蒋越翻过计分板，露出两个空白的零。我站了很久，最后只做了准备动作，没有把球发出去。唐宁看出我在拖延，说可以从头再来，却不能装作刚才那次已经完成。那句话本来只关乎训练，我却在回程的车上反复想着。车窗里映出我自己的脸，后面忽然叠上姐姐翻册子的手；等我低头去看，手机里只有一条沈乔发来的消息，问我周末是否有空。我没回。她问的是周末，我脑子里却还站在那条白线上。

那天的车也许并不是从球馆开出的。我常把几个地方的灯光记成同一种颜色。面向成年学员的夜校里有间校医室，周岚在那里做健康咨询，三十八岁，讲话很慢。我曾去问过一次睡眠的问题，进门前想好了许多形容词，坐下却只说“最近不太好”。她把笔放在桌上，问“不太好”是入睡难、醒得早，还是醒后再睡不回去。我在日记里让她问了更多，也让自己回答得比当时诚实；真实的记录只到她在表格里写下“待确认”为止。后来有一页写唐宁把计分板推到她面前，周岚又接过球，说我既然来了就该把动作做完。我知道这不可能：周岚不打那支球队，她的桌上也没有球。可是我总舍不得划掉那一页。两个人隔着不相干的场所，居然都让我把含糊的地方说清楚。

林见工作的店开在另一条街，门口没有招牌，玻璃上贴着褪色的营业时间。她三十岁，是那里的店员，说话像先在心里排过顺序；二十六岁的林栀是她妹妹，笑起来和她很像，却喜欢等别人把话说完。那天我走进去时，林见正在整理三张空白卡片。她说自己偏向“S”，习惯先提出规则；林栀在隔壁喊她，说自己的“M”是愿意依照商定的步骤来，别替她省掉确认。我第一次听她们这样介绍自己，倒觉得两人说的不是同一件事。林见带我进左边的会谈室，三张卡一字摆开，让我写下愿意谈、暂时不谈、还需确认的事。我写第三张时停了很久，她把笔帽推过来，没有看我的字。隔壁传来一下轻响，像有人把计时器放在桌上。我不记得门当时关没关，也不敢说林栀听见了我们的话。等我敲了隔壁的门，林栀才让我进来，要我照着自己写下的顺序读卡。我念到第二张卡时改了口，她按停计时器，等我重新决定。日记后来把这两间房写得像一条走不完的走廊；实际上从左边出来，往右转两步就到了。

我原本打算把那几张卡寄给姐姐，最终没寄。地铁上我捏着信封，旁边一位穿办公室工牌的女人问我是不是陆闻。她叫何冉，三十五岁，我们在朋友的聚会上见过一次。她的同事叶舒，三十二岁，站在几步之外看线路图。何冉问我为什么每次提到姐姐都像要向谁交作业。我说没有，她却指指我手里的信封，问敢不敢现在给陆遥打个电话，把邀请她来看我这件事说清楚。车到站时，人群挤过我们之间。何冉没有碰到我，她只等着，仿佛我一伸手就能从口袋里拿出一个答案。我记得自己看见了姐姐的号码；我也记得自己把手机锁了屏。日记的一行写“陆遥接了，沈乔就在她旁边，提醒我别又改时间”，紧挨着的下一行却写“号码没有拨出去”。哪一行都没有删。叶舒那时还在看线路图，列车门开了，她先下车，我连她有没有听见何冉那句话都不知道。

再翻两页，林见似乎也上了那节车厢。她手里拿着卡片，问我第三张还要不要保留；唐宁在车门上方翻计分板；周岚隔着玻璃纠正我把“也许”说成“肯定”。我写到这里才发现自己把灯光、白线和车厢里的扶手缠在一起了。林见没有上过地铁，唐宁也不可能带着计分板追来。可每次写到姐姐，我就想起她那本薄册子，接着想起唐宁让我回到发球线的声音，最后又看见林栀按停计时器的手。她们没有相遇，是我让她们在纸上相遇。大学同学顾青和我同岁，只在页边写过一句“把人物关系画出来，别再认错”，我连那是不是他的笔迹都不确定。写着写着，我竟把他安进了店铺的走廊；这一句我划掉了，他那天不在那里。

沈乔后来真给我打过一次电话，问我便条写完没有。我刚从夜校出来，路边的风把纸吹得翻了面。我说还没写好，她没有替我催姐姐，也没有问信封寄出去了没有，只说写不下去就先留白。我站在便利店门口，看玻璃里的自己像站在排球馆那条线后。何冉的问题、林见的卡片和周岚的表格这时都挤在一起，连我也分不清先想起的是哪一个。那晚我回家把便条重新铺平，第一行仍是空的。那些让我反复重写的场面，我有的经历过一小截，有的纯粹是想象；它们在日记里靠得很近，在生活里却未必连得上。

现在纸到了你手里。接待室的桌面很空，我把两只手放在桌沿，等你翻过第一页。外面的响动隔着门传来，我看不见那里是谁。你抬头时，我忽然不想让你替我猜下一页，只想听你先问我一句话。

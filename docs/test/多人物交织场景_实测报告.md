# 多人物交织场景实测报告

测试日期：2026-09-28。当前正文约 2,408 个汉字，包含 12 名成年人。标准答案现在按人物组织：名称、一句话描述，以及一段 300–400 个汉字的连贯事件描述。事件描述交代角色怎样行动、陆闻怎样回应、事情停在何处，同时说明回忆、想象或互斥分支的边界。原文锚点用于核查，不再把每个动作拆成独立事件。

项目现有 `preview_preset` 与 `deep_preview_preset` 均列出 11 名非叙述者角色，陆闻另在用户身份栏；当前接待室场景正确。深度分析形成 13 条时间线记录，但不能自动产出这 12 段完整的人物事件叙述，顾青与陆闻在大学画关系线的互动也没有入时间线。因而标准答案是供后续模型比较的人工目标，不代表现有模型已经做到。

`多人物交织场景_v1_模型直读原始输出.txt` 保留了较早版本的失败样本：模型曾把不确定的公寓拜访当成事实，并混淆地铁电话分支。它不用于给当前版本打分。

快速校验：`.venv/bin/pytest -q backend/tests/test_docs_test_fixture.py`。验收页面由 `python3 scripts/build_test_review.py` 从正文和标准答案生成。
